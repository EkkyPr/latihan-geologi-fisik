# Latihan Soal Geologi Fisik

Kumpulan soal latihan untuk mahasiswa Geologi Fisik.  
**50 soal** mencakup Tektonik Lempeng, Siklus Batuan, dan Batuan Beku.

---

## Struktur Soal

| Tipe | Jumlah |
|---|---|
| Pilihan Ganda (PG) | 25 |
| Benar / Salah (B/S) | 10 |
| Isian | 15 |

## Peta Keterampilan Hitungan

| Keterampilan | Soal |
|---|---|
| Hitung sudut dip dan klasifikasi | 2, 10, 13 |
| Hitung kedalaman dan pilih prospek | 7, 8, 15 |
| Panjang bidang (Pythagoras), konversi satuan, waktu | 3, 9, 16, 33 |
| Nama batuan dari komposisi mineral | 35, 48, 49 |

---

> Angka pada soal hitungan berbeda dari soal ETS.  
> Soal non-hitungan tidak berubah dari alur ETS.
